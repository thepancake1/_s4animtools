# s4animtools

S4AnimTools is a toolset for making animations and poses for The Sims 4. Actively tested with Blender 3.6 and above, but may work with earlier versions above 2.8.

### Features:
# **Import multi-actor animations into the game super easily**

In Sims4Studio's animation tools, you can only import one clip at a time. This is fine for poses, but for something like a two sim social interaction with a prop, it can get tedious selecting a sim, then importing, selecting the other sim... and so on until all actors in the scene have been imported.

# **Keep multiple in-game clips in one blend file**

If you're working on sim to object animations, it's super handy to have the ability to split an animation sequence into tiny parts. You can have an animation for the "getIn", the "getOut" and all the other animations for the sim and the object in one file!

# **Design animations to support more body shapes**

If you watch EA animations closely, you may notice that the hands adjust in order to not clip with the body of the sim. s4animtools supports assigning slot assignments and baking the animation data required to get it working in-game.

s4animtools is not designed to replace Sims4Studio, but rather complement it. You'll need to use S4S in order to get object and sim models and rigs from the game. s4animtools is also still very much WIP, so tutorials for it aren't common yet.
